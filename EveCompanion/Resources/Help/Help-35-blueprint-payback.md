Thinking about buying a new blueprint? This page shows how quickly each one would earn back its price.

## Controls

- **Buy blueprint at**: the hub whose sell orders set the blueprint's price.
- **Sell at**: one hub or the best hub.
- **Assume ME**: a freshly bought blueprint is ME 0. Pick a higher number to see payback after you've researched it.
- **Hide ones I own**.
- **Search**, **Category** and **Group**.

## Columns

- **Blueprint Price**: shown in orange if the market has no seller and CCP's base price is used. It says *Not sold on the market*, *Invention only* (for T2) or *You own it* where those apply.
- **Gain / Run**: what one run earns compared with selling the materials, the same as Build vs Sell.
- **Runs to Pay Back**: green when it's 20 runs or fewer, orange when it's over 100.
  - **Never +x ↑** means a run currently loses money. *x* is how much the item's price would need to rise for the build to break even. The arrow shows which way the price has been heading over the last week.
- **Build Time**: how long those pay-back runs take in one slot.
- **Market Days**: how long the market would take to absorb that many.
- **Gain / Hour** and **Sold / Day**.

The list starts with the fastest payback, then the ones that never pay back.
