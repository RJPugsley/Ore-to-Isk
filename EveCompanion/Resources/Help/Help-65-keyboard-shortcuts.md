- **⌘1 to ⌘5**: Pilot, Mine, Build, Sell, Haul tabs
- **⌘R**: refresh character data
- **⌘,**: Settings (login, confirmations)
- **⇧⌘O**: Ore Database in its own window
- **⌘?**: this Help
- **⌥⌘?**: help for the page you're on
- **Arrow keys + Return**: pick a search suggestion
- **Esc**: close a search suggestion list
